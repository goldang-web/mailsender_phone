# 모바일 메일 클라이언트

FastAPI 서버와 연동되어 설정을 받아오고, 단일/배치 발송 및 로컬 DB 동기화를 처리하는 단일 CLI입니다.

## 주요 기능
- 서버에 디바이스 이름만 등록하면 자동으로 ID 발급 및 설정 동기화
- 서버에서 내려준 DB 파일 주입(Inject) 요청 처리
- 단일/배치 발송 명령을 실행하고 결과를 서버에 실시간 보고
- 도메인별 로컬 DB 상태(총 레코드, 발송 성공/실패 등) 수집 후 하트비트로 전송

## 준비 사항
1. `uv` 또는 `pip`로 가상환경을 생성합니다.
2. `requests` 라이브러리만 설치하면 됩니다.

```bash
uv venv .venv
source .venv/bin/activate
uv pip install requests
```

## 실행 방법
```bash
uv run python main.py
```
- 실행 후 나타나는 메뉴에서 `2`번으로 서버 주소, `3`번으로 디바이스 이름을 설정합니다.
- `1`번 "서버 연결"을 선택하면 하트비트를 시작하며, `Ctrl+C`로 종료할 수 있습니다.
- 서버와 정상 연결되면 대시보드에서 디바이스 카드가 활성화됩니다.

## 주요 파일
- `main.py`: 디바이스 등록, 하트비트, 작업 처리의 진입점
- `smtp_utils.py`: Telnet 기반 SMTP 발송 유틸리티
- `lib/test.py`: EUC-KR 헤더/본문 처리를 담당하며 텔넷 로그를 수집하는 하위 라이브러리
- `data/`: 도메인별 로컬 DB 저장 경로 (`naver/naver.db`, `daum/daum.db`)
- `settings.json`: 서버 주소, 디바이스 이름/ID, 동기화 정보 등의 로컬 설정

텍스트(.txt) 형태의 주소 목록을 업로드하면 클라이언트가 자동으로 SQLite DB로 변환하여 Inject합니다.
